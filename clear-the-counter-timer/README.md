# ⏱️ Clear the Counter Timer

A simple JavaScript project that demonstrates how to create and stop a counter using `setInterval()` and `clearInterval()`.

## 📌 Project Overview

This project starts a timer that increments a counter every second. Clicking the **Clear** button stops the timer immediately.

It is a beginner-friendly project to understand JavaScript timers and DOM manipulation.

## 🚀 Features

- Live counter updates every second.
- Stop the counter with a single click.
- Clean and responsive UI using Bootstrap.
- Beginner-friendly JavaScript implementation.

## ⚙️ How It Works

1. The counter starts from **0**.
2. `setInterval()` calls a function every **1000 milliseconds (1 second)**.
3. The function increments the counter and updates the displayed value.
4. Clicking the **Clear** button triggers `clearInterval()`, stopping the timer.

1. Download or clone this repository.
